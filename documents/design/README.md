# Design files

Mockups made for gate 2 (design direction) and any design handed over later. `documents/DIRECTION.md` ("デザインの方向") points here.

- `mock-<date>/`: the artboards of a Claude Design canvas (`canvas.json` and one `*.dc.html` per artboard, as published) plus `index.html`, a standalone page that stacks the same artboards so they can be viewed without the canvas runtime. The canvas link is in the gate 2 issue; the files here are the copy that survives account or artifact changes.
